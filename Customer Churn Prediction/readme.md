# Customer Churn Prediction using Machine Learning

## Project Overview

This project is a Machine Learning-based Customer Churn Prediction System that predicts whether a customer is likely to leave a company’s service.

Customer churn prediction helps businesses identify customers who may stop using their services so they can take preventive actions and improve customer retention strategies.

Example:
A telecom company can use this system to identify customers who are likely to discontinue their subscription.

---

## Problem Statement

Companies lose revenue when customers leave their services. Predicting customer churn in advance helps businesses:
- Reduce customer loss
- Improve customer satisfaction
- Create targeted retention strategies
- Increase overall business growth

---

## Features Used

The model analyzes customer-related information such as:
- Monthly Charges
- Contract Type
- Internet Service
- Payment Method
- Customer Tenure
- Online Security
- Tech Support
- Streaming Services
- Total Charges
- Senior Citizen Status

## Machine Learning Algorithms Used

- Easy to interpret

### 2. XGBoost Classifier
- Advanced boosting algorithm
- High prediction performance
- Widely used in industry and Kaggle competitions
