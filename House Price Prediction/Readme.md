# House Price Prediction using Machine Learning

## Project Overview

This project is a Machine Learning-based House Price Prediction System that predicts house prices based on various property features such as area, quality, number of bedrooms, garage capacity, and more.

The project was built using Python, Scikit-learn, XGBoost, and Streamlit.

---

## Features

- Data Cleaning & Preprocessing
- Feature Engineering
- Regression-based Prediction
- XGBoost Regressor Model
- Interactive Streamlit Web Application
- Real-time House Price Prediction

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Joblib
- Matplotlib

---

## Dataset

Dataset used:
Kaggle House Prices Dataset

The dataset contains housing-related features such as:
- Lot Area
- Overall Quality
- Basement Area
- Living Area
- Number of Bedrooms
- Garage Capacity
- Year Built
- and more.
